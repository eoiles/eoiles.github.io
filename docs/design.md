# 体验与动效设计

2026-09-19：以转换工具为中心调整布局。

## 一件专注的文字工作台

桌面原文与转换结果并排，手机原文在上、结果在下。页面标题缩成一行功能说明，打开即可输入；不再为宣传标题或独立预览保留大块空间。

编码文本、点阵、黑白格共用一个固定高度的结果区，默认直接显示可编辑的 Unicode 编码。切换不增加页面长度，复制始终紧邻结果。示例、撤销、清空集中在输入下沿。首次打开不唤起键盘；两侧均可编辑。

手机的可视化单格自动使用 8px，桌面使用 14px，不增加尺寸按钮。较长内容在结果区内滚动；超过预览数量上限仍明确标注，复制与导出完整。图片导出使用固定 14px 单格，不受手机预览缩放影响。

深色采用近黑 `#101213`、石墨 `#16191B` 和少量冰青 `#B4EEEB`；浅色采用雾白 `#F0F1EE`、纸白 `#FCFCF9` 与深青 `#21655F`。冰青用于复制与当前交互重点。普通操作使用透明或细线按钮，避免整排青色大色块。黑白格的 1 / 0 仍固定为纯黑 / 纯白。

实际输入内容构成主要字号重点。状态与统计保持安静；编码方式使用两个轻量选择项，点击即生效，并就地标明保留原文还是编码。示例、清空、撤销复用状态行，格式和展示方式始终独立。

品牌编码来自实际 `enc('eoiles')`，图标来自 `enc('e')`。系统字体不引入额外请求；不添加账号、分析、复杂依赖或用户文本持久存储。

## 动效的层次

- 首屏只播放一次 360–440ms 的轻淡入；标题轻移 7px。内容从开始就可交互，编辑区不作位置移动。延迟最多 110ms。
- 主要动作的触感为 100–180ms：悬停轻抬 1px，按下轻压，复制成功在原按钮绘制勾号，文案出现但按钮宽度保持不变。
- 聚焦编辑器时，侧边细线与标签平滑亮起。桌面精确指针可带动极淡的边缘光；不使用持续帧循环，触屏与减少动态效果模式关闭跟随光感。
- 三种结果视图共用一个 280ms 滑动选中背景；编码与可视化之间以 180ms 淡入衔接，保留输入 DOM、选区和滚动位置。点阵与黑白格之间，实际点位保留同一 SVG 节点和坐标，以 240ms 变化半径和缩放，沿阅读方向错开 0–50ms。快速切换可以反向继续。
- 连续输入只更新改变的点，新增或移除必要单元；现有 SVG 节点保留，不重新播放整块入场动画。转换本身没有人为延时。
- 菜单约 200ms 展开、140ms 收起；帮助约 280ms 展开、220ms 收起。再次点击从当前状态继续，取消过期动画，不抢走正在编辑的焦点和选区。
- 主题以约 260ms 的颜色过渡衔接，主题符号轻转；没有阻塞页面的全屏遮罩。
- 错误与手动复制区平滑展开或收起。手机浮动复制只在主要复制按钮离开视口时出现，过渡过程中也保持在可见范围。
- 共享缓动为 `cubic-bezier(.22,.8,.25,1)`。无持续闪烁、自动播放教学或无限装饰动画。

## 可访问性与边界

尊重 `prefers-reduced-motion`；偏好在操作中途改变时，正在进行的面板过渡会结束到目标状态，教学仍由用户主动逐步操作。按钮与表单保留键盘焦点提示；关闭中的菜单与内容不可被误操作。

手机检查 320、375、430px，横屏及缩小视口。保留 VisualViewport、安全区、输入法组合、错误恢复、准确复制、完整图片导出和本地隐私。真实 iOS/Android 软键盘及读屏测试的限制见验证记录。

核心算法仍是独立且简洁的 `src/core.js`。视觉重设计、增量 SVG 更新及所有动效都在外围实现。


## 编码方式与阅读帮助的修订

用户面对的是「自然顺序」而非内部名称「魔法数字」。选择直接作用于最近实际编辑的一侧；没有第二次确认，撤销可恢复选择和内容。显示风格仍完全独立。格式不自动猜测，Unicode 原生只作为旧编码兼容选项。

空页面的教学提供 A / 中 / 😀 三个可点示例，取代不可移动的 1/1 数字输入。已有文字按用户看到的字选择，前后箭头浏览；emoji 与组合序列不拆成不可见按钮，多组点阵通过局部前后按钮查看。手机始终只渲染当前字附近少量选项，不生成长文字列表。

阅读示意固定实际 Unicode 位置，改变的是编号与播放路径。自然顺序从左上开始向下；原生模式从右下开始，按位权 128、64、32、16、8、4、2、1 读出。每步同步突出对应圆点、编号与二进制数字，箭头立即落在当前位置，避免多个箭头交叠。两种格式的教学都有独立位置断言。

解释只保留当前顺序和操作所需的一句话。原理先展示文字 → 二进制 → 点阵，源码默认再折叠一次；实际打包源码在本地着色，长行换行，不制造双向滚动框。UTF-16 等实现细节不再作为主界面的操作名称。

错误输入保留时，教学明确使用「上次有效结果」及其真实格式；输入修复后跟随新结果更新。所有改动都在外围，历史核心及三个协议字面量未改动。
