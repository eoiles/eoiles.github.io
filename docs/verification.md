# 实际验证记录

验证日期：2026-09-17；精简版复核：2026-09-18。Windows 本机，Node.js 20.17.0，Vite 6.4.3；Playwright 使用已安装的 Google Chrome 和下载的 WebKit 26.6。手机是浏览器设备/视口模拟，不能等同于真实 iOS/Android 系统。

## 协议

`npm test`：40 项全部通过。

- 用户要求的 A、中、😀 三个精确向量。
- 全部 256 个字节：独立位移公式、正向排列、逆排列。
- 八个单置位字节：左列从上到下，再右列从上到下；在浏览器 DOM 上再检查实际 SVG 坐标。
- 历史原生格式独立向量与全字节测试。
- 空文本、首尾空格、制表符、LF、CRLF、单 CR、组合字符、ZWJ 家庭与职业 emoji、代理码元、BOM/变体选择符。
- 非法字符位置、奇数长度、前后 U+2800、主动空白清理不删除 U+2800。
- 全部 65,536 个 UTF-16 码元在两种格式下往返一致。

## 浏览器

在原仓库生成的生产构建 `dist` 上，桌面 Chrome、Pixel 7 配置的移动 Chrome、iPhone 13 配置的 WebKit 共 **54 项功能/无障碍检查通过**。其中 53 项在完整生产回归中直接通过；WebKit 双主题无障碍检查触及默认 30 秒测试时限，调整该项预算至 60 秒后单独复核，39.5 秒完成且没有违例。未更改应用代码来规避检查。手动复制回退也验证了原始 CRLF 的保留。

另外生成了 10 张深浅主题/不同宽度截图和一段约 13 秒的实际交互录屏；非桌面视频记录任务按设计跳过。

`npm run build`、TypeScript 类型检查、`git diff --check` 均通过；`/` 和 `/index.html` 的生产入口正常，`/index.html` HTTP 状态为 200。

覆盖：首次打开不聚焦、即时转换、连续编辑、最近编辑侧、模拟 compositionstart/input/compositionend、点阵与黑白格共用节点、格式保护、清空与示例撤销、错误修正、奇数长度、主动清理与恢复、剪贴板成功与失败、CRLF 粘贴后继续编辑、长输入与旧结果竞争、仅偏好持久化、Worker 与存储失败回退、主题跟随系统、主动教学和减少动态效果、编辑器选区/焦点/内部滚动保持。

导出验证：SVG 包含每个完整单元和全部 bit；2,200 个盲文字符的 SVG 不受 256 个预览上限影响。PNG 检查实际尺寸、文件签名，以及首白/黑模块/尾白的 RGBA 像素。超出安全画布时明确报错而非裁切。

自动无障碍：axe WCAG 2 A/AA、WCAG 2.1 AA；深浅主题、有效预览和展开的帮助/设置/源码、错误状态，无报告违例。发现的浅色英文小标对比度不足已修复。这不能替代真人读屏测试。
